Privacy Policy

Effective date: 2026-09-22

Personal AI Assistant is a private household assistant used by the owner and invited family members. This policy explains what data may be processed when the assistant is connected to Google services or other approved services.

What data may be accessed

  • Google Calendar data that you explicitly allow the assistant to access
  • Google Tasks data that you explicitly allow the assistant to access
  • Gmail data that you explicitly allow the assistant to access
  • Files, messages, and attachments that you explicitly send to the assistant

How data is used

  • To answer questions and carry out the assistant functions you request
  • To create, update, and retrieve calendar events, tasks, emails, and files when authorized
  • To store operational state needed to run the assistant

Sharing

Data is not sold. Data is not used for advertising. Data is shared only with the services you connect and only as needed to provide the assistant functions you request.

Storage

The assistant is designed to run on a private self-hosted setup. Files and workflow state may be stored on the owner-controlled system for operational purposes.

Contact

Questions about this policy can be sent to the project owner using the contact email configured for the assistant project.
